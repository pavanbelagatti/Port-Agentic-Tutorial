## 🚀 Port Agentic Tutorial — Building AI Agents with Port as Context Layer
### What if your AI Agents had real engineering context instead of guessing?

This project demonstrates how to build a multi-agent system where
Port.io acts as the context lake powering intelligent, grounded responses.

- Analyzes operational signals (incidents, deployments)
- Generates a human-friendly response
